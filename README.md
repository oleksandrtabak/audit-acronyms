# Абревіатури та основні терміни у аудиті 
    
     
     
|      |                                                           | **📝 Робочі скорочення (специфічні для PwC)**     |
| ---- | --------------------------------------------------------- | :------------------------------------------------ |
| EGA  | **E**vidence **G**athering **A**ctivity                   | Дії з збору доказів під час аудиту                |
| FSLI | **F**inancial **S**tatement **L**ine **I**tem             | Конкретна стаття фінансової звітності             |
| CD/W | **C**ontrol **D**eficiency / **W**eakness                 | Недоліки або слабкі місця у внутрішньому контролі |
| ET   | **E**ngagement **T**eam                                   | Команда аудиторів по конкретному клієнту          |
| BP   | **B**usiness **P**rocess                                  | Бізнес-процес клієнта                             |
| ECL  | **E**ntity **L**evel **C**ontrol                          | Контроль на рівні компанії                        |
| ICFR | **I**nternal **C**ontrol over **F**inancial **R**eporting | Внутрішній контроль фінансової звітності          |
| ITGC | **I**nformation **T**echnology **G**eneral **C**ontrol    | Загальні IT-контролі                              |
| LSPM | **L**ikely **S**ources of **P**otential **M**isstatement  | Джерела потенційних помилок                       |
| WCGM | **W**hat **C**ould **G**o **M**rong                       | Що може піти не так (аналог EY)                   |
| RMM  | **R**isk of **M**aterial **M**isstatement                 | Ризик суттєвого викривлення фінансової звітності  |
|    |    |    |    |
|        |                                                                 | **🏛 Інституції**                                        |
| PCAOB  | **P**ublic **C**ompany **A**ccounting **O**versight **B**oard   | Регулятор аудиту публічних компаній у США                |
| ISA    | **I**nternational **S**tandards on **A**uditing                 | Міжнародні стандарти аудиту                              |
| SOX    | **S**arbanes-**O**xley **A**ct                                  | Закон США про фінансову звітність та внутрішній контроль |
| SEC    | **S**ecurities and **E**xchange **C**ommission                  | Регулятор фондового ринку США                            |
| FCA    | **F**inancial **C**onduct **A**uthority                         | Регулятор фондового ринку Великої Британії               |
| НКЦПФР | **Н**аціональна **К**омісія з цінних паперів та фондового ринку | Регулятор фондового ринку України                        |
| ESMA   | **E**uropean **S**ecurities and **M**arkets **A**uthority       | Регулятор фондового ринку Європи                         |
|    |    |    |    |
|     |                                         | **⚠️ Ризик та комплаєнс**                         |
| PEP | **P**olitically **E**xposed **P**erson  | Політично значущі особи                           |
| UBO | **U**ltimate **B**eneficial **O**wner   | Кінцевий бенефіціарний власник                    |
| KYC | **K**now **Y**our **C**ustomer          | Процедури ідентифікації клієнта                   |
| AML | **A**nti-**M**oney **L**aundering       | Протидія відмиванню коштів                        |
| FDD | **F**inancial **D**ue **D**iligence     | Фінансова перевірка перед угодою                  |
| SAR | **S**uspicious **A**ctivity **R**eport  | Звіт про підозрілі операції                       |
| CTR | **C**urrency **T**ransaction **R**eport | Звіт про валютні операції                         |
|    |    |    |    |
|     |                                           | **🏢 PwC внутрішні**             |

| TLP | **T**ax, **L**egal and **P**eople         | Податково-юридичні та HR-послуги |

| TS  | **T**ransaction **S**ervices              | Сервіси з транзакцій             |
| IFS | **I**nternal **F**irm **S**ervices        | Внутрішні сервіси фірми          |

Цей репо створено як невеличкий словник-шпаргалку на основі моєї роботи на посаді фінансового аналітика в PwC (частково був залучений до відділу Assurance для переоцінки фінансових інструментів).
